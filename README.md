# AI-BinCalc
Binary All-in-One Tool — jeden plik HTML zamienił się w dwanaście modułów JS. Karteczki, kalkulator, konwerter, quiz, lekcje, reprezentacje, porównanie, bit po bicie, arkusz, trener. Cztery języki, trzy motywy, dźwięk, localStorage.

# Binary All-in-One Tool

Jeden plik HTML → dwanaście modułów JS. Bez builda, bez zależności.
Otwierasz `index.html` i działa.

## Co to jest

Narzędzie do nauki systemu dwójkowego: 10 widoków, 4 języki, 3 motywy.
Port 1:1 z monolitu (~2900 linii) — bez zmian funkcjonalnych.

## Szybki start

1. Sklonuj / rozpakuj
2. Otwórz `index.html` w przeglądarce
3. Gotowe

Serwer nie jest wymagany (klasyczne `<script>`, wspólny scope).

## Widoki

| Widok | Co robi |
|---|---|
| Karteczki | bity na sznurku, klik/drag |
| Kalkulator | + − × ÷, U2, Booth, bitwise, animacja |
| Konwerter | dec ↔ bin, okres, IEEE 754 |
| Quiz | losowe zadania, egzamin, słupkiem |
| Lekcje | 7 tematów × 4 kroki + własne |
| Reprezentacje | unsigned / SM / U2 |
| Porównaj | `< = >` |
| Bit po bicie | kolumna po kolumnie |
| Arkusz | zadania do wydruku |
| Trener | słabe punkty, heatmapa, sesja |
